# Ashen-Veil-Project
A Game
Ashen Vigil is a 2D Souls-like action game that runs in your browser. You fight through three trials, each ending in a boss fight: the Ashen Warden, Sir Vael the Gilded and the dragon Cinderwing. Stamina management, rolling, parrying and resting at bonfires all matter.

Before each run you choose a race with its own buffs and two weapons from a set of five, including a fast, dexterity-based Katana. You can play the fixed campaign or a seeded random world. There's also a secret Pig character, unlocked with a password. It works with keyboard, Xbox-style controllers and touch screens, and scores go on a leaderboard.
